Ques 1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.

Ans 1. Frontend: Part users see (UI).
Example: Buttons, forms, and layouts on Amazon’s website (HTML, CSS, JS).
Backend: Logic and database handling.
Example: Order processing and payment on Amazon (Node.js, Python, Java).
Full Stack: Works on both frontend & backend.
Example: A developer building both the user interface and server logic.

Ques 3. Describe how a browser requests and displays a web page from a web server.

Ans. 1.User enters URL.
2.Browser sends HTTP request to server.
3.Server sends HTML, CSS, JS files.
4.Browser renders them into a web page.

Ques 5. Explain what a web server is and give examples of commonly used servers. 

Ans.A web server stores, processes, and delivers web pages to clients.

Ques 6. Define the roles of a frontend developer, backend developer, and database administrator in a project. 

Ans. Frontend Developer: Designs UI/UX and builds client-side code.
Backend Developer: Manages server logic, APIs, and data processing.
Database Administrator (DBA): Handles data storage, backups, and optimization.

Ques 8. Explain the difference between static and dynamic websites. Provide an example of each. 

Ans. Static: Fixed content, same for all users.
Example: Portfolio website.
Dynamic: Content changes with user interaction or database.
Example: Facebook, Amazon.
